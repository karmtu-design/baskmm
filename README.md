# Bask Metals and Mining — портфель недропользования

Внутренняя система группы: компании-недропользователи, их лицензии на разведку и добычу,
контуры участков на карте. Доступ только для сотрудников, по почте и паролю.

## Что уже работает (этап 1)

- Обзор портфеля: карта всех участков, ближайшие сроки лицензий, компании.
- Карта участков с фильтрами по компании, виду лицензии и полезному ископаемому;
  подложки «Схема», «Спутник», «Топо» и объёмный «3D-рельеф» (MapLibre GL).
- Карточки компаний с реквизитами и списком лицензий.
- Карточка лицензии: сведения, изменение данных, контур участка.
- Ввод контура: угловые точки из приложения к лицензии (градусы-минуты-секунды или
  десятичные градусы, WGS-84 или СК-42) либо файл KML, KMZ, GeoJSON.
  Выгрузка контура в KML для Google Earth.

- Реестр лицензий (`/licenses`): поиск, фильтры, сортировка по любому столбцу, скрытие столбцов,
  выгрузка в Excel вместе с координатами контуров.
- Загрузка лицензий из Excel (`/licenses/import`): шаблон, предпросмотр с проверкой каждой строки,
  создание недостающих компаний, обновление существующих лицензий по номеру, контуры с листа «Координаты».

- ИИ-ассистент (кнопка «Ассистент» на каждой странице): отвечает на вопросы по реестру лицензий
  и компаниям со ссылками на карточки. Работает через Claude API (модель по умолчанию `claude-sonnet-5-5`,
  меняется переменной `ANTHROPIC_MODEL`). Ключ `ANTHROPIC_API_KEY` хранится в настройках Vercel,
  в браузер он не попадает. Без ключа кнопка показывает, что ассистент ещё не подключён.

- Геоанализ (Turf.js): на вкладке «Карта и геоанализ» карточки лицензии — пересечения с другими
  участками группы, буферная зона вокруг контура, ближайшие населённые пункты, дороги, железная дорога
  и ЛЭП (данные OpenStreetMap через Overpass API). Страница «Геоанализ портфеля» (`/analysis`):
  общая площадь, все пересечения и ближайший соседний участок для каждой лицензии.
- Скважины в 3D (deck.gl): вкладка «Скважины 3D» в карточке лицензии — стволы скважин с окраской
  интервалов по содержанию, бортовое содержание, лучший интервал по каждой скважине, загрузка и выгрузка
  в Excel (листы «Скважины» и «Интервалы»). На участке Юкон загружены тестовые скважины ТЕСТ-01…08.
- Презентации (`/presentations`): загрузка файлов до 50 МБ (PDF, PowerPoint, Word, Excel, картинки),
  привязка к проекту и языку, скачивание и отправка: самим файлом через окно «Поделиться» телефона,
  ссылкой в WhatsApp, Telegram, по почте или копированием (ссылка действует 1, 7 или 30 дней).
  Файлы хранятся в закрытом хранилище Supabase Storage (bucket `presentations`).
- Потенциальные проекты (`/projects`): реестр рассматриваемых объектов с этапами, условиями и следующим
  шагом; добавление, изменение и удаление; загрузка из Excel и выгрузка в Excel (сопоставление по названию).
- Кнопка «Все разделы» (на главной и в шапке, также Ctrl + K): список всех страниц. Переходы между страницами анимированы (React View Transitions).

## Устройство

Next.js 16, Supabase (база, вход), MapLibre GL (карта), deck.gl (3D-скважины), Turf.js (геоанализ). Оформление построено на библиотеке
[Once UI Core](https://github.com/once-ui-system/core) (лицензия MIT) в стиле шаблона Magic Portfolio;
код самого шаблона не используется. Цвета, тема и фон настраиваются в `src/resources/once-ui.config.ts`. Публикуется в Vercel автоматически
при каждом изменении ветки `main`. Настройки подключения к базе хранятся в Vercel:
`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
Рабочий файл карты `public/vendor/maplibre-gl-worker.mjs` копируется из `node_modules`
автоматически при установке и сборке (`scripts/copy-map-worker.mjs`).
